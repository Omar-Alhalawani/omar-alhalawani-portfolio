# Project navigation and mounting update

Project models now open their case studies through a real WebGL camera push. The selected module stays locked, retains the existing 0.22 elevation, rotates slightly toward its case-study angle, and receives stronger local amber activity. Other signal paths recede. The normal camera path is 520 ms on desktop and 360 ms on touch; destination preparation can briefly hold the final pose, with a 1.4-second navigation deadline.

On hover intent (180 ms), keyboard focus, or touch selection, only that route, its module scripts, and its scene/renderer chunks prepare. HTML project cards and Open Project share the same navigation function. Offscreen/unavailable worlds and reduced motion use normal navigation. Modifier clicks retain ordinary browser behavior.

The actual final rendered frame is carried through session storage and installed before destination paint. The corresponding hero enters from a compatible camera angle and core scale, then settles into its normal composition. The captured frame covers loading until the hero is ready; a six-second upper bound permits static fallback. The View Transition API provides a 90 ms optional bridge from the completed camera push to its retained frame. Promise cancellations and unsupported browsers fall back to normal navigation. Cross-document automatic transitions are not enabled: the capture browser aborted their opt-in, so the explicit bridge is used instead. This keeps existing multi-page Astro navigation instead of introducing a persistent canvas or a client router.

FIFO's default informational selection no longer elevates it. All six modules have mounting docks and aligned inner hardware origins. Actual hover/focus/touch intent alone elevates a module. Pointer exit restores exact rest unless a genuine focus or touch selection remains. The 0.22 active rise is unchanged. Renderer arbitration now preserves its winner with a margin while still pausing on hidden documents. Resource release checks cache identity and acquires resources before paint.

Four additional verified public repositories are now linked conditionally; unpublished projects have no disabled source button. Project pages include Previous / All Projects / Next links and an active sticky section index. DAQ uses the same four-channel core as the project platform.
