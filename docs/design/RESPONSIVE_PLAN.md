# Responsive plan

- ≥1600px: content max1440; large wafer with restrained surrounding space, no stretched ultra-wide text.
- 1024–1599px: 46/54 text/art balance; maintain a readable heading and 3 actions without overlap.
- 768–1023px: art shifts below/alongside introductory copy; multi-column grids reduce.
- <768px: copy first; constrained ~340px hero visual beneath it. Stack explanation becomes a full-width HTML list with a lightweight layer graphic. Projects and case studies become single-column. Navigation is a native details menu with a visible trigger.
- Short landscape: min-height content determines layout; no text clipping or forced viewport-sized panels.

Canvas and imagery have reserved dimensions. Interactive demos wrap controls and preserve 44px targets. Long email addresses, source URLs, and code tokens wrap where appropriate. Tables scroll inside a labeled region rather than making the page overflow.

Required inspection sizes: 1280×720, 1366×768, 1440×900, 1920×1080, 2560×1440, 320×568, 375×812, 390×844, 430×932, and 768×1024; include ultrawide when practical. Test live resizing, touch, fast/reverse scroll, menu, and PDF access.
